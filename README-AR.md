# QUREO Study Mate — الإصدار 2.0

مساعد تدريبي مستقل بواجهة عربية، يعمل بـ JavaScript وNode.js.

## ما الذي يعمل؟
- كتابة السؤال أو إرفاق صورة له (PNG/JPG/WEBP).
- تصغير الصورة في المتصفح لتقليل حجم الإرسال.
- إرسال السؤال والصورة والكود إلى نموذج ذكاء اصطناعي يدعم واجهة Chat Completions ومدخلات الصور.
- شرح باللغة العربية.
- سجل محلي لآخر 20 سؤالًا على نفس المتصفح.
- نسخ النتيجة.
- واجهة متجاوبة مع الهاتف والكمبيوتر.
- مسار فحص صحة الخادم `/api/health`.

## التشغيل محليًا
يتطلب Node.js 18 أو أحدث:
1. فك ضغط المشروع.
2. افتح الطرفية داخل المجلد.
3. شغّل `npm start`.
4. افتح `http://localhost:3000`.

## ربط نموذج الذكاء الاصطناعي
اضبط متغيرات البيئة على الخادم:
- `AI_API_URL`: عنوان Chat Completions لدى مزوّدك.
- `AI_API_KEY`: مفتاح سري من مزوّد الذكاء الاصطناعي.
- `AI_MODEL`: اسم نموذج يدعم الصور إذا كنت تريد تحليل الصور.

لا تضع المفتاح داخل `public/app.js` أو أي ملف يُرسل للمتصفح، ولا ترفعه إلى مستودع عام. يجب أن يكون المزوّد متوافقًا مع تنسيق Chat Completions ورسائل `image_url` للصور. تختلف أسماء النماذج وسياسات الاستخدام والتكلفة حسب المزوّد.

## النشر على Render
1. ارفع المشروع إلى مستودع Git.
2. أنشئ Web Service واربط المستودع.
3. Build command: `npm install`
4. Start command: `npm start`
5. أضف متغيرات البيئة الثلاثة في إعدادات الخدمة.
6. بعد نجاح النشر ستحصل على رابط عام من Render. ملف `render.yaml` يحدد إعدادات أولية.

يمكن نشره على أي استضافة Node.js تدعم Node 18+ ومتغيرات البيئة.

## الحدود والخصوصية
- هذا المشروع لا يسجل الدخول إلى QUREO ولا يقرأ صفحاتها تلقائيًا ولا يتجاوز أنظمة الحماية.
- استخدمه للتدريبات والمراجعة وفهم الأكواد. لا ينفذ اختبارات مُقيّمة أو يرسل إجابات نيابة عن الطالب.
- الصور والأسئلة تُرسل إلى مزوّد الذكاء الاصطناعي الذي تختاره عند الضغط على زر التحليل. راجع سياسة ذلك المزوّد.
- سجل الأسئلة يُحفظ في `localStorage` على نفس المتصفح ويمكن مسحه من واجهة الموقع.
- لا يوجد حساب مستخدم أو قاعدة بيانات أو حفظ سحابي في هذا الإصدار.
